# QA Testcase Generator

This skill analyzes requirement documents and generates structured manual test cases.

## Input
- BRD
- PRD
- SRS
- User Stories
- Feature descriptions

## Output Columns

- Case ID
- Case Title
- Case Description
- Precondition
- Test Steps
- Expected Result
- Execution Status
- Comments

## Usage

Provide requirement text as input.

The skill returns structured test cases suitable for Excel export.
